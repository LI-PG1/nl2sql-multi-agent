# 数据字典（表与字段说明）

> 由 `config/schema_notes.yaml` 渲染生成；Olist 巴西电商库（9 张表）。

## 表：orders
- 说明：订单主表（每行一个订单）
  - order_id：订单 ID
  - customer_id：客户 ID（外键 → customers）
  - order_status：订单状态：delivered / shipped / canceled / unavailable / processing 等
  - order_purchase_timestamp：下单时间
  - order_approved_at：支付时间
  - order_delivered_customer_date：客户签收时间（空 = 未送达）
  - order_estimated_delivery_date：预计送达时间

## 表：order_items
- 说明：订单商品明细（商品金额与运费分开）
  - order_id：订单 ID（外键 → orders）
  - order_item_id：订单内商品序号
  - product_id：商品 ID（外键 → products）
  - seller_id：卖家 ID（外键 → sellers）
  - price：商品金额
  - freight_value：运费

## 表：order_payments
- 说明：订单支付表（一个订单可有多条支付记录）
  - order_id：订单 ID（外键 → orders）
  - payment_type：支付方式（credit_card / boleto / voucher / debit_card）
  - payment_installments：分期数
  - payment_value：支付金额（销售额默认口径字段）

## 表：order_reviews
- 说明：订单评价表
  - order_id：订单 ID（外键 → orders）
  - review_score：评分（1-5）
  - review_comment_message：评论文本
  - review_creation_date：评价发起时间

## 表：customers
- 说明：客户表（每行对应一个订单的客户快照）
  - customer_id：客户 ID（订单粒度）
  - customer_unique_id：客户唯一 ID（跨订单去重统计用）
  - customer_state：客户所在州
  - customer_city：客户所在城市
  - customer_zip_code_prefix：邮编前缀

## 表：products
- 说明：商品表
  - product_id：商品 ID（表内无商品名称字段，商品标识即此字段）
  - product_category_name：品类名（葡语原值）
  - product_weight_g：商品重量（克）
  - product_photos_qty：图片数量

## 表：sellers
- 说明：卖家表
  - seller_id：卖家 ID
  - seller_state：卖家所在州
  - seller_city：卖家所在城市

## 表：geolocation
- 说明：邮编地理表（邮编前缀 → 州 / 城市 / 经纬度）
  - geolocation_zip_code_prefix：邮编前缀
  - geolocation_state：州
  - geolocation_lat：纬度
  - geolocation_lng：经度

## 表：category_translation
- 说明：品类名翻译表（葡语 → 英语）；品类输出默认经此表转英文
  - product_category_name：品类名（葡语）
  - product_category_name_english：品类名（英语）
