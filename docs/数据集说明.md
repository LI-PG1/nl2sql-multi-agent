# 数据集说明（data-agent）

> 全部为公开数据集；数据本体不入库（`.gitignore` 已排除 `data/raw/`），由 `python scripts/fetch_data.py` 一键拉取（已就绪自动跳过；亦支持按名称单独拉取）。
> 本文件记录：各数据集的角色、用途与接入点、校验结果、许可。

## 二、用途与接入点

### 1. Olist — 主业务库（已接入）
- **发布时间**：2019 年由 Olist 在 Kaggle 公开巴西电商真实订单数据，为长期可获取的公开数据集，早于本项目周期；
- 全链路开发（Schema 索引 / Schema Linking / few-shot / 执行守卫）与自建黄金集评测均基于此库；
- 9 张关联表（订单 / 明细 / 支付 / 评价 / 商品 / 卖家 / 客户 / 地理 / 品类），天然支持"多表 join + 口径歧义"场景：商品金额 vs 含运费 vs 支付总额；取消订单是否扣减；下单时间 vs 支付时间。

### 2. BIRD Mini-Dev — 跨库泛化评测（已接入 · 外测轨）
- **发布时间**：2024-06 由 BIRD 团队（香港大学与阿里巴巴）官方发布，GitHub 与 HuggingFace 长期可获取，早于本项目周期；
- BIRD（NeurIPS 2023）开发集的小型版本：500 题覆盖 11 个真实数据库；每题含 `evidence`（作答所需外部知识提示）与 `difficulty`（简单 148 / 中等 250 / 困难 102）；
- 用途：验证 pipeline 在"未经专门适配"的库上的泛化能力（Schema Linking 候选压缩 → SQL 生成 → 执行比对）；
- 接入点：M4 评测扩展——在自建黄金集之外增加一组"跨库对照"；`evidence` 字段可对照本项目口径层的处理方式。
- **执行记录（2026-05-12）**：外测轨首跑全量 500 题 → 执行准确率 **272/498 = 54.6%**（simple 65.5% / moderate 52.6% / challenging 43.6%）；报告 `eval/report_external_bird.md`、运行器 `eval/run_external.py`。

### 3. CSpider — 中文语义解析对照（已接入 · 外测轨）
- **发布时间**：2019 年随 EMNLP 2019 论文发布（中山大学），公开渠道长期可获取；
- dev 集 1034 条中文问题、覆盖 20 个库，含 gold SQL（可执行比对）；"中文提问、英文表名"结构与本项目设定一致，是与本项目最贴近的公开中文 NL2SQL 数据；
- 用途：中文提问理解与 Schema Linking 的补充验证；问题风格亦可用于校准自建黄金集的出题口径；
- **执行记录（2026-05-12）**：外测全量 1034 题 → 执行准确率 **559/814 = 68.7%**（205+15 条价值型中文问句因参考集为空/全 NULL 跳过——中文取值与英文库数据的既有口径差，按约定不判分；失败抽样确认以真实错误为主）；报告 `eval/report_external_cspider.md`、运行器 `eval/run_external_sets.py`。

### 4. Spider 1.0 — 数据库底座（执行依赖）
- **发布时间**：2018 年随 EMNLP 2018 论文发布（耶鲁大学），公开渠道长期可获取；
- 166 个 SQLite 库；CSpider 的全部 20 个目标库均在其中（已校验无缺失）；
- 用途：为 CSpider 提供可执行环境；其余库可作跨库冒烟素材。

### 5. Sakila / Chinook / Northwind — 轻量冒烟
- 经典小库（DVD 租赁 / 音乐商店 / 贸易），表少、体积小、schema 干净；
- 用途：快速验证"任意 SQLite 库可接入"（索引构建 → 检索 → 执行的最小端到端链路）。

### 6. UCI Online Retail II — 备选业务库
- 英国零售流水（单表，约 100 万行）；Olist 替换或"多业务库切换"演示时启用。

### 7. Archer — 双语复杂推理基准（设计参照 + 评测扩展）
- 公开版含 10 个可执行数据库，中英各 518 题（train 414 + dev 104）、259 条唯一 SQL；题目按 `reasoning_type` 标注（算术 / 常识 / 假设推理），部分附 `commonsense_knowledge`；测试集（另 10 库）用于官方榜、未公开；
- 用途：① 复杂推理题目的**分层设计参照**（自建黄金集"推理类"扩展）；② M4 评测扩展——跨库 + 推理对照（VA / EX 口径）；③ 中文长句问法的多样性参考；
- 接入点：M4 评测扩展。
- **执行记录（2026-05-12）**：外测全量 1036 题（zh/en × dev/train）→ 执行准确率 **238/1012 = 23.5%**（zh/dev 15.0%｜zh/train 24.1%｜en/dev 19.0%｜en/train 26.1%；24 条跳过）。难度定位＝多跳反事实推理强集；失败抽样确认为真实错误（派生量计算 / 参数快照类）。报告 `eval/report_external_archer.md`。

### 8. 中文 Text2SQL 样本（DuSQL 标注体系）— 标注结构参考（设计素材）
- 魔搭官方「中文Text2SQL数据集」：train 500 + test 100 条（每条一文件）；字段体系（`action` / `conds` / `schema_link` / `header_knowledge` / `history_sql` / `wvi_corenlp`）与 DuSQL 一致，含 schema linking 与表头知识标注；
- 用途：① 中文问法与**标注结构参考**——对齐本项目 Schema Linking / 口径层的标注设计；② 自建中文黄金集出题口径的多样性来源；
- 注意：**不含数据库本体**，仅作设计参考、不用于执行评测；DuSQL 全量（200 库）需 Luge 平台登录，未引入（见附录）。

### 9. KDD DataSpace 公测参考包 — 官方基准外测（已接入 · 外测轨）
- KDD Cup 2026 Data Agent Track 官方基准 DataSpace（HF 镜像 `HKUSTDial/DataSpace`）：410 题输入 + 60 题公测参考包，异构工作区（csv / json / sqlite / 文档 / PDF / 视频），约 2.68 GiB；
- 用途：在 BIRD / CSpider / Archer 之外，覆盖"任务内多文件工作区 + 文档型数据 + 官方评测器判分"的基准形态；
- 接入点：`eval/kdd_prepare.py`（SHA256 校验 → 60 题逐题建库：1233 表 + doc_chunks 4189 块 + 任务简报）→ `eval/run_kdd.py`（双链路 A/B）+ 官方评测器（vendored `eval/kdd_evaluator/`）；
- **执行记录（2026-05-26）**：60 题全量 → Task Accuracy **A 单发 14/60（23.3%）｜B 取数+解读 12/60（20.0%）**（v2 提示词纪律+重试工程，较 v1 双链路零退化各 +3/+2 题）；视频模态本环境不可解析（28/60 题含视频，已分层披露）；报告 `eval/report_kdd.md`。

## 附录：候选评估记录（2026-04-22）

> 本轮对 HuggingFace（镜像）/ 魔搭 / GitHub / 官方站等多源候选做了系统评估，结论如下：

| 候选 | 来源 | 结论 |
|---|---|---|
| CHASE（中文多轮 text-to-SQL） | 原 GitHub 仓库已下线、无可靠镜像 | **未采用**（来源失效） |
| CoSQL（英文多轮） | HF 镜像（avandar2024/cosql，含 166 库） | **备选**（镜像许可未标注 + 当前管线为单轮；多轮扩展时再引入） |
| DuSQL 全量（200 库） | Luge 平台（需登录） | **未采用**（获取门槛）；标注样本已由魔搭镜像取得（见 #8） |
| ChineseText2SQL-180K / SynSQL-2.5M / Gretel 等 | HF / 魔搭 | **未采用**（训练规模数据集；建设期不训练，few-shot 与评测集自建） |
| CSpider+DuSQL 转换版（sql-create-context 格式） | HF / 魔搭 | **未采用**（问答对转换版、无库；与已有 CSpider 原件重复） |
