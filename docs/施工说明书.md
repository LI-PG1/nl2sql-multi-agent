### 0.3 终端 10 分钟入门

**四个必会技巧**：

**路径怎么写**（Windows 路径 → Git Bash 写法）：
- 例：`D:\projects\data-agent` → `/d/projects/data-agent`（盘符变小写、反斜杠变斜杠）；
- 路径含空格、或拿不准时，用引号包起来：`cd "/d/projects/data-agent"`。


### 0.5 给项目建一个"独立环境"（本步最重要）

**为什么要建**：Python 的包（比如 pandas）装在"环境"里；直接全局装，项目之间可能要的版本不一样、会打架。**venv（虚拟环境）＝给每个项目一个独立的"依赖书包"**——Python 工程的标准做法，也是你以后每个项目都会用到的技能。

**动手（6 步，全在 Git Bash 里；以下用 `python` 示意，按 0.3 你通过的方式替换）**：
1. 进入项目：
   ```bash
   cd "/d/projects/data-agent"
   ```
2. 确认 Python 可用：
   ```bash
   python --version        # 预期 Python 3.12.x
   ```
3. 创建独立环境（会在项目里生成一个 `.venv` 文件夹，等 10–30 秒）：
   ```bash
   python -m venv .venv
   ```
4. 激活它（**每次开工都要做的第一步**）：
   ```bash
   source .venv/Scripts/activate
   ```
   成功标志：提示符**最前面出现 `(.venv)`**，像这样：
   `(.venv) 用户名@电脑名 MINGW64 /d/.../data-agent`
5. 修复 pip 证书问题（本机确诊：pip 配置里有一个指向 `X:\科研\...` 的失效证书路径，不修的话以后装包会报 SSL 错误）：
   ```bash
   python -m pip config unset global.cert
   ```
   看到 "Removing…" 之类输出即成功。
6. 升级 pip 到最新（顺手体会一下"装东西"的完整流程）：
   ```bash
   python -m pip install --upgrade pip
   ```

**收工**：`deactivate` 可以退出环境（提示符前面的 `(.venv)` 消失）——今天不用，知道有这回事即可。

**快速通道（备用）**：如果 `.venv` 一时建不起来，也可先用本机其他可用的 Python 3.12 顶上（命令按你的实际安装路径调整），但**建议之后回到本步补齐自建环境**——它是每个项目的标配技能。

### D2｜数据落地与画像

**目标**：亲手把数据从 0 拉到本地、建库、生成画像；理解"口径歧义"不是编的，是从真实数据里长出来的。

**先理解（为什么）**：主库用 Olist（公开、真实、9 张表关联丰富、含退款与多状态订单）——"公开数据打底、口径层与评测集自建"是纪律。数据里天然并存三个金额字段：`payment_value`（支付额）/ `price`（商品额）/ `freight_value`（运费）——这就是口径歧义的源头；先看画像、再设计歧义，是方法论。

**动手**
1. 拉取数据：`python scripts/fetch_data.py`（全量约 560MB，已就绪自动跳过；也可按需 `python scripts/fetch_data.py bird archer`）。
2. 建库：`python scripts/build_db.py` → `data/orders.db`（约 143MB）。

### D12｜第一轮迭代闭环

2. 定向改进（对照《详细设计》§8 映射表选）：
   | 失败类型 | 改哪里 |
   |---|---|
   | schema_miss | `schema_notes.yaml` / `synonyms.yaml` / top-k |

## 附录 B｜排错清单

| 症状 | 处理 |
|---|---|
| `python` 命令找不到 | 改用 `py -3.12`，或全路径 `/c/Users/你的用户名/AppData/Local/Programs/Python/Python312/python.exe`；重装时记得勾 "Add python.exe to PATH" |
| "找不到包" / `pip 不是内部命令` | 环境没激活：`source .venv/Scripts/activate`（提示符前面要有 `(.venv)`） |
| `(.venv)` 没出现 | 激活没成功——重试 D0 第 4 步；确认项目里已有 `.venv` 文件夹 |
| pip 装包 SSL 报错 | 先根治：`python -m pip config unset global.cert`（常见根因：`C:\Users\<你的用户名>\AppData\Roaming\pip\pip.ini` 的 cert 配置指向失效路径）；仍异常再用备用源：`python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn --trusted-host files.pythonhosted.org` |
| 中文乱码 | `export PYTHONIOENCODING=utf-8` |
| `sentence-transformers` 装不上 | 保持 mock 后端 + 记录 issue（不阻塞） |
| `No module named src` | 必须在项目根目录（`data-agent/`）执行 |
| `app.py` 没走真实 LLM | 未读到 `LLM_API_KEY`；检查 `.env` 是否在项目根目录 |
| 换服务商 404 | `LLM_BASE_URL` 缺 `/v1` 或模型名不对 |
| 想看库但没 sqlite3 命令 | 用 Python 一行查库（见 D2） |
