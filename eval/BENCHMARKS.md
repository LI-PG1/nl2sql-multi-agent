## 口径与边界

- 外测模式统一：全库 schema 注入 + 生成模板 + 守卫 + 执行反馈重试 + 规范化结果集比对；Olist 专属口径层 / 索引 / few-shot 关闭；
- 参考结果集为空 / 全 NULL 行按约定跳过（不判分；CSpider 的 220 条＝中文取值与英文库数据的既有口径差）；
- 多步集为单条级采样波动区间（27–29/30；失败均为模型未遵守既有纪律的个例，无系统性退化）；
- 规模实验室的"放大"为压测（合成数据，非业务数据）；并发压测未列入本表；
- KDD DataSpace 公测（#8）：异构工作区（csv/json/sqlite/文档/PDF/视频）统一适配；视频模态在本环境不可解析（28/60 题含视频，已分层披露）；判分为官方评测器（vendored），链路与 BIRD/CSpider/Archer 同源但任务形态不同（任务内多文件工作区 + 文档型数据），分数与其余基准不可横向比较；
- 评测范围：公开基准使用各数据集的开发/测试子集（BIRD Mini-Dev、CSpider 测试集、Archer 全量、DataSpace 公测 60 题）；KDD 410 题全量输入保留在官方侧，本工程跑公测参考包；
- 生成模型为自部署端点，各基准口径见对应报告；
- 范围外扩展项（不影响本表结论）：Gradio 交互界面、生成侧缓存与多轮会话。
